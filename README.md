# JUST BUY A HOUSE! — JMT Games

Prototype public v0.7 : clicker satirique en français, jouable dans le navigateur.

- Choix : Génération Boomer (1975) ou Génération X (1995).
- Un clic fait avancer de trois mois de vie.
- Épargne, prélèvements, immobilier et remboursement d'un crédit.
- Les scénarios économiques sont fictifs et ne constituent pas des données historiques.

Le jeu est disponible dans `index.html`, sans framework, compte ou service payant.
